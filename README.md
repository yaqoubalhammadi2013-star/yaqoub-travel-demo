# YAQOUB TRAVEL

YAQOUB TRAVEL is a responsive, premium flight-search experience designed for comparing flights from Abu Dhabi (AUH) and Dubai (DXB), selecting destinations, and refreshing live data via a secure backend.

## What is included

- Premium dark navy + turquoise travel UI
- Search form with destination country and city selection
- Popular destination cards, airport data, and IATA codes
- Comparison between AUH and DXB departures
- Real live flight search via a secure Node/Express backend
- Filters for cheapest, fastest, non-stop, airline, departure window, and price range
- Save-trip tracking, price target management, and export functionality
- PWA manifest and service worker for installability on mobile devices
- Graceful handling when the API is not configured or unavailable

## Project structure

- `index.html` – main frontend page
- `styles.css` – full responsive styling and design system
- `script.js` – client-side destination logic, flight search UI, filters, saved trips, and PWA registration
- `server.js` – secure backend for Amadeus API calls and route protection
- `package.json` – Node app configuration
- `.env.example` – environment variable template
- `public/manifest.webmanifest` – installable app manifest
- `public/sw.js` – service worker
- `public/logo.svg` – YAQOUB TRAVEL logo

## Requirements

- Node.js 18+
- npm
- An Amadeus for Developers account with production or test credentials

## Installation

1. Clone the repository.
2. Open a terminal in the project folder.
3. Run:

```bash
npm install
```

4. Copy the example environment file:

```bash
cp .env.example .env
```

5. Add your Amadeus credentials to `.env`:

```env
PORT=3000
AMADEUS_CLIENT_ID=your_client_id
AMADEUS_CLIENT_SECRET=your_client_secret
NODE_ENV=development
```

## Start the app

### Development mode

```bash
npm run dev
```

### Production mode

```bash
npm start
```

The app will be available at:

- Frontend: http://localhost:3000
- API: http://localhost:3000/api/health

## Live flight API setup

This project is designed to use the Amadeus Flight Offers Search API securely from the backend instead of exposing credentials in browser JavaScript.

Follow the official documentation:

- https://developers.amadeus.com/
- https://developers.amadeus.com/self-service-apis/category/flight

Important:

- Amadeus test credentials are used against `https://test.api.amadeus.com`.
- Production access is required before live production data can be used in a commercial environment.
- Never expose API keys in public JavaScript or repository files.

## Backend integration notes

The app calls the backend endpoint `/api/search` from the frontend. The backend performs secure OAuth token exchange and flight-offer requests. The browser receives only filtered, safe JSON results.

If the Amadeus credentials are missing, the app gracefully displays a clear error instead of showing fake data.

## GitHub Pages deployment

The frontend is static and can be deployed to GitHub Pages.

### Steps

1. Push this repository to GitHub.
2. In GitHub, go to the repository settings.
3. Open Pages.
4. Select the branch to publish.
5. Set the folder to `/` or use a static output directory if your project is split later.
6. Save the settings.

Your public frontend URL will be generated by GitHub Pages.

## Secure backend hosting

Use a secure backend host such as:

- Render
- Railway
- Fly.io
- Heroku
- Azure App Service
- DigitalOcean App Platform

### Recommended setup

- Deploy `server.js` as a Node application
- Set environment variables in the hosting dashboard:
  - `PORT`
  - `AMADEUS_CLIENT_ID`
  - `AMADEUS_CLIENT_SECRET`
  - `NODE_ENV=production`
- Point the frontend to the deployed backend URL (for example `https://your-backend.example.com`)

## Custom domain setup

If you want a custom domain:

- Configure the DNS records for your frontend host
- Add the domain to GitHub Pages or the backend host
- Update your frontend API base URL accordingly

## Notes on booking and pricing

- The app does not fabricate prices or availability.
- When Amadeus is not configured, it does not pretend to have real flight results.
- Booking links are displayed only when returned by the live provider or available from the booking response.
- Any paid API limits or subscription requirements must be reviewed with the provider before production usage.
